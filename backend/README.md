# FloodMap Live — Geospatial Radar Backend Service
### FastAPI + Shapely + NASA Earthdata Integration Microservice

This microservice provides automated satellite radar bitemporal change detection, permanent water masking, and multi-sector geographic impact analytics for the **FloodMap Live** platform.

---

## 1. Quickstart: Running the Backend

### Prerequisites
- Python 3.10+ (tested on Python 3.14)
- `pip` package manager

### Step 1: Install Dependencies
```bash
cd backend
pip install -r requirements.txt
```

### Step 2: Configure Credentials in `.env`
Open [`backend/.env`](.env) and add your NASA Earthdata login credentials:
```env
EARTHDATA_USERNAME=your_username
EARTHDATA_PASSWORD=your_password
```

### Step 3: Launch the Server
```bash
cd backend
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

Interactive Swagger documentation is available at:
👉 **`http://localhost:8000/docs`**

## 2. API Endpoints Overview

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/v1/health` | Service health, NASA auth verification, indexed dataset count |
| `GET` | `/api/v1/manifest` | Serves the dataset manifest generated by the discovery indexer |
| `GET` | `/api/v1/observations` | Lists all indexed and live SAR acquisitions |
| `GET` | `/api/v1/flood-extent` | Returns classified surface water GeoJSON (with permanent water subtraction) |
| `GET` | `/api/v1/impact-analysis` | Computes district, village, and cropland impact using `Shapely` |
| `POST` | `/api/v1/search-earthdata` | Searches NASA's Common Metadata Repository (CMR) for satellite radar granules |
| `POST` | `/api/v1/process-flood` | Executes algorithmic bitemporal change detection on two radar passes |
| `GET` | `/api/v1/rainfall` | Returns meteorological rainfall time series records |
